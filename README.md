Objective
The objective of this lab is to practice using formatted output, escape sequence characters, and proper code documentation in Java. Students will design and implement a Java program that displays their initials within a decorative, boxed format while adhering to strict formatting and output requirements.



Problem Description
Write a Java program that displays your initials on the screen using formatted output.

If a student’s name is Nik Glory, the output should display NG.

If a student’s name is Alex Anderson, the output should display AN, where N represents the second letter of the last name, since the first letters of the first and last names are identical.

The final output must be very similar in size and alignment to the provided sample but must be original in design and not an exact copy.



Functional Requirements
The program must display:

The first letter of the student’s first name, and

The first letter of the student’s last name.

If the first letters of the first and last names are the same, the program must display the second letter of the last name instead.

The initials must be displayed side by side.

The output must be enclosed in a decorative box.

The box design must differ from the sample provided.

Students may use characters of their choice.

Letters may be displayed in uppercase or lowercase.
